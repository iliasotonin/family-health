# Как вести семейный архив вместе с Claude Code

Интерфейс кабинета удобен, чтобы смотреть на данные и вести дневники. Но чтобы **собрать** архив —
десятилетие анализов в PDF, сканы без текста, фото бумажных бланков, генетику, выписки — и потом
**разобраться** в нём, лучше работает агент Claude Code, запущенный в папке проекта. Этот документ
описывает, как это делать, и какие ошибки мы уже совершили за вас.

Правила для самого агента лежат в [CLAUDE.md](../CLAUDE.md) — он прочитает их сам. Здесь то, что
стоит знать человеку.

---

## Как это выглядит на практике

1. **Запустите кабинет** по README и заведите членов семьи в интерфейсе.
2. **Сложите документы в папку вне проекта** — например, `~/health-vault/`. Как угодно: по годам,
   по людям, вперемешку. Агент разберёт.
3. **Откройте Claude Code в папке проекта** и попросите: «разбери папку `~/health-vault/…`, занеси
   в кабинет». Агент заведёт реестр файлов, определит, чей каждый документ, распознает, занесёт.
4. **Задавайте вопросы**: «почему у жены падает ферритин», «сверь мою генетику с анализами»,
   «что из рекомендаций врача так и не выполнено», «разбери головокружения по данным Whoop».
5. **Проверяйте вывод глазами**, особенно всё, что касается детей и генетики (см. ниже).

Агент пишет разовые скрипты импорта в `scripts/` — эта папка в `.gitignore`, в них ваши данные.

## Что нужно понимать про точность

**Агент ошибается, и ошибки медицинские.** Всё, что ниже, — реальные случаи из разбора одного
архива. Каждая ошибка звучала уверенно и логично.

**Генетика — чаще всего перевёрнутая трактовка.** Трижды за месяц агент правильно называл генотип и
делал противоположный вывод: «ваш вариант снижает активность», хотя снижает как раз другой аллель.
Особенно коварно, когда соседние варианты одного участка обозначаются противоположными буквами:
в одном «плохой» аллель — T, в соседнем тот же самый «плохой» вариант — C.
**Правило:** для каждого вывода по генетике спрашивайте, *какой именно аллель рисковый* и сверено
ли это с сырыми данными чипа.

**Выводы по двум точкам.** Агент увидел два совпадающих значения с разницей в семь лет и объявил
«стабильно низкое — конституциональная особенность». Когда нашлись ещё пять замеров между ними,
оказалось, что низким было только одно. **Правило:** «тенденция» — только по полному ряду.

**Один показатель вне контекста.** Сывороточное железо скачет в течение суток и при любом
недомогании. Один низкий результат — не «многолетний дефицит». Запасы железа показывает ферритин.

**Норма бланка ≠ клинический порог.** Лаборатория может поставить нижнюю границу ферритина 10,
а дефицитом по критериям ВОЗ считается ниже 15. Агент должен отмечать, когда флаг выставлен
не по бланку, и почему.

**Строка «BRCA1» в потребительском генетическом отчёте** почти никогда не означает патогенную
мутацию — это распространённые полиморфизмы. Не повод для паники и не замена секвенированию.

## Как не перепутать людей

Это главный риск семейного архива: анализ одного человека записан другому.

- **Принадлежность — только по бланку**: фамилия, имя, дата рождения на самом документе. Не по
  названию папки и не по имени файла.
- **Папки врут.** В одной папке могут лежать бланки нескольких детей. Файл «Гистология» может
  оказаться биопсией другого органа, чем вы думаете.
- **Фото одного и того же документа** с разных ракурсов — не два документа.
- **Опечатки в бланках бывают**: неверный год рождения при верных фамилии и клинике. Агент должен
  отметить это в записи, а не выбросить документ и не создать нового человека.
- **Когда документы противоречат друг другу** («беременностей не было» в одной выписке и рубец
  после кесарева на МРТ пятью месяцами раньше), приоритет у объективного исследования,
  а само противоречие записывается.

## Как не потерять файлы

Когда документов больше десятка, агент начинает «помнить», что что-то разобрал, хотя не разобрал.

- Попросите **реестр**: каждый файл с контрольной суммой, человеком и статусом
  (`внесено / дубликат / уже было / пропущено с причиной`). В конце — сверка «на диске = в реестре,
  незакрытых ноль».
- **«Не читается» — не приговор.** Сканы без текстового слоя читаются как изображения; рукописное
  разворачивается и увеличивается; `.webarchive` из Safari — это обычный архив, распаковывается.
  Агент однажды пометил такой файл нечитаемым, не попробовав, — внутри была единственная запись
  о ранней потере беременности.
- **«Пропущено» должно быть проверено глазами**, а не по названию папки. Папка «согласия» оказалась
  действительно согласиями — но это выяснилось, только когда их открыли.
- Паспорта и другие документы, удостоверяющие личность, агенту разбирать не нужно.

## Whoop: что он умеет и чего нет

- **Recovery, HRV, пульс покоя считаются по ночи.** Про дневное самочувствие, давление стоя,
  обезвоживание они ничего не говорят. «Восстановление 92, а голова тяжёлая» — не противоречие.
- **Непрерывного пульса и журнала Whoop в API нет.** Суточный средний и максимальный пульс, SpO2,
  температура кожи и расход калорий — есть и синхронизируются. Журнал (алкоголь, кофеин) доступен
  только через выгрузку данных в самом приложении Whoop.
- **Часовой пояс каждого дня виден в данных** — по нему восстанавливаются поездки и можно сравнить
  самочувствие в разных местах. Но пояс ≠ город: в одной зоне оказываются десятки городов.
- **Даты сдвинуты:** recovery относится к утру, нагрузка — к предыдущему дню. При сравнении
  «нагрузка → восстановление» агент должен выравнивать на день.

## Приватность при работе с агентом

- Всё, что агент читает, уходит модели. Для этого проект и создан, но стоит понимать.
- **Вторая модель для проверки** (например, аудит кода другим ИИ) — ограничивайте её тем, что
  собираетесь публиковать. Базу, документы и скрипты импорта ей читать незачем.
- Если будете дорабатывать код и публиковать изменения: включите хук
  (`git config core.hooksPath .githooks`) и заведите `.pii-patterns` со своими фамилиями, датами
  рождения и номерами медкарт. Хук остановит коммит, в котором они есть.

## Это не врач

Агент хорошо находит в архиве то, что десятилетиями лежало на разных бланках у разных врачей.
Но результат его работы — **список вопросов к врачу**, а не диагноз и не назначение. Хорошая
сводка звучит так: «вот цифры, вот что они вместе означают, вот к какому специалисту и с чем идти».
