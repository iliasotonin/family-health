# 🩺 Семейный кабинет здоровья

Самостоятельно размещаемый сервис для здоровья всей семьи: загрузка анализов и генетических тестов,
динамика показателей, дневник самочувствия и питания, интеграция с Whoop и AI-сводки от Claude.
База и файлы хранятся у вас (SQLite + диск). **Распознавание документов и сводки идут через
Anthropic API** — см. раздел «Данные и приватность».

> **In English.** A self-hosted family health tracker: upload lab PDFs and genetic tests, get the
> values extracted by Claude, chart every marker over time against its reference range, keep a
> symptom and food diary, sync Whoop. Single-password, single-family, SQLite. The UI is in Russian.
> Documents you upload are sent to the Anthropic API for extraction. Not a medical device.

## Прежде чем начать — честно о состоянии проекта

Проект вырос из одного семейного архива, и заполняли его не так, как предполагает интерфейс.

**Проверено в работе:** хранение, графики динамики с нормами, дневники самочувствия, питания и
лекарств, прививки, генетика, синхронизация Whoop, вход по паролю.

**Написано, но ни разу не запускалось с настоящим ключом Anthropic:** автоматическое
распознавание загруженного PDF («загрузил — показатели извлеклись сами») и генерация AI-сводки.
Весь исходный архив (сотня с лишним документов за десять лет) заносил не интерфейс, а агент
Claude Code, работающий в папке проекта. Если встроенное распознавание ошибётся или упадёт —
это ожидаемо, сообщите.

**Главное, что стоит понять заранее:** приложение — это аккуратная полка для данных. Выводы вроде
«откуда анемия», «что из генетики подтверждается анализами», «какой анализ десять лет висит без
контроля» получались не функциями приложения, а работой агента поверх собранного архива.
Лучше всего проект работает в связке **«приложение + Claude Code в этой папке»**. Как это делать —
в [docs/claude-code-workflow.md](docs/claude-code-workflow.md); правила для самого агента лежат в
[CLAUDE.md](CLAUDE.md) и подхватываются автоматически.

**Что понадобится:**

- Node.js 20+, терминал, умение запустить `npm install`;
- свой ключ Anthropic API (платный, по факту вызовов) — для распознавания и сводок;
- Claude Code — если хотите разбирать архив так, как описано выше;
- по желанию — приложение разработчика Whoop;
- интерфейс только на русском.

Это самостоятельно размещаемый проект: каждая семья запускает свою копию, данные остаются у неё.
Общего сервиса нет.

## Что умеет

- **Профили членов семьи** — я, супруг(а), дети; возраст, пол, аватары.
- **Загрузка документов** — PDF анализов, фото, генетические тесты (Genotek). Claude извлекает
  показатели/варианты автоматически *(см. оговорку выше: этот путь ещё не проверен вживую)*.
- **Динамика** — графики каждого показателя во времени с референсным коридором и флагами
  «выше/ниже нормы».
- **Ручной ввод** — быстрый ввод веса, давления, температуры, пульса, сатурации и др.; дневник
  самочувствия; лекарства и добавки; прививки (в т.ч. детские).
- **Питание** — дневник еды с калориями, белком и алкоголем, дневные цели, график «съедено /
  потрачено по Whoop / вес».
- **Генетика** — распознанные значимые варианты, сгруппированные (фармакогенетика, носительство,
  предрасположенности, питание).
- **Whoop** — подключение по OAuth, синхронизация recovery / сна / нагрузки / HRV, пульса за
  сутки, SpO2, температуры кожи и расхода калорий; графики за любой период.
- **AI-инсайты** — Claude смотрит на анализы + Whoop + дневник + генетику и пишет сводку динамики,
  флаги и вопросы к врачу. **Это навигация по данным, не диагноз и не назначение.**

Всё под общим паролем доступа.

## Стек

Next.js 16 (App Router) · React 19 · Prisma 6 + SQLite · Anthropic SDK · Recharts · Tailwind 4.

## Запуск локально

```bash
npm install
cp .env.example .env                    # затем заполнить (см. ниже)
npx prisma migrate deploy               # создать БД из миграций
git config core.hooksPath .githooks     # защита от случайного коммита личных данных
npm run dev                             # http://localhost:3000
```

Первый экран — ввод пароля (`APP_PASSWORD` из `.env`). Дальше «Добавить члена семьи».

## Переменные окружения (`.env`)

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | `file:./dev.db` локально; строка `postgresql://…` на сервере |
| `DATA_DIR` | папка для загруженных файлов (по умолчанию `./data`) |
| `APP_PASSWORD` | пароль доступа ко всему кабинету. Заглушка `change-me` не принимается |
| `AUTH_SECRET` | секрет подписи сессии, **обязателен**, не короче 32 символов: `openssl rand -hex 32` |
| `ANTHROPIC_API_KEY` | ключ Anthropic — нужен для распознавания документов и AI-сводок |
| `ANTHROPIC_MODEL` | модель (по умолчанию `claude-sonnet-5`) |
| `WHOOP_CLIENT_ID` / `WHOOP_CLIENT_SECRET` | из приложения на developer.whoop.com |
| `WHOOP_REDIRECT_URI` | должен совпадать с redirect в кабинете Whoop |

Без `AUTH_SECRET` или с паролем-заглушкой кабинет не пустит никого и скажет, что сервер не настроен —
встроенного запасного секрета нет намеренно: код открыт, и любой запасной вариант позволял бы
подделать вход.

Без `ANTHROPIC_API_KEY` UI работает, но загрузка/парсинг/инсайты вернут понятную ошибку.
Без Whoop-переменных вкладка Whoop показывает инструкцию по настройке.

### Настройка Whoop

1. Зайти на https://developer.whoop.com → создать приложение.
2. Scopes: `read:recovery read:sleep read:cycles read:profile offline`.
3. Redirect URL — ровно то, что в `WHOOP_REDIRECT_URI` (локально
   `http://localhost:3000/api/whoop/callback`).
4. Скопировать Client ID / Secret в `.env`, перезапустить, на вкладке Whoop нажать «Подключить».

### Получение ключа Anthropic

console.anthropic.com → API Keys. Расходы идут по факту вызовов (парсинг документа и генерация
сводки — по одному запросу).

## Данные и приватность

- База: файл `dev.db` (SQLite). Загруженные файлы: `DATA_DIR/uploads/`. Оба в `.gitignore`.
- **Что уходит наружу.** Каждый загруженный документ целиком отправляется в Anthropic API для
  распознавания. AI-сводка отправляет туда же имя, возраст, показатели, дневник и генетику члена
  семьи. Whoop API получает только запросы синхронизации. Больше внешних вызовов нет.
  Условия хранения данных — в политике Anthropic для API. Если это неприемлемо, не задавайте
  `ANTHROPIC_API_KEY`: кабинет работает с ручным вводом.
- Скрипты разового импорта своих данных держите в `scripts/` или `private/` — оба каталога в
  `.gitignore`.

### Защита от случайной публикации

`git config core.hooksPath .githooks` включает pre-commit-хук. Он останавливает коммит, если в нём
есть база, геном, `.env`, файлы из `scripts/`, `private/`, `data/` — или строки из вашего
локального `.pii-patterns`: одно регулярное выражение на строку (фамилии, даты рождения, номера
медкарт). Этот файл в `.gitignore`, список не публикуется.

## Известные ограничения

Проект рассчитан на одну семью и один сервер за туннелем. Перед тем как открывать его в интернет:

- **Не выставляйте порт напрямую.** Ставьте за Cloudflare Tunnel или VPN. Ограничение попыток входа
  доверяет IP из заголовков `cf-connecting-ip` / `x-forwarded-for` — без доверенного прокси их
  можно подменить.
- **Сессия не отзывается.** Cookie действует 30 дней; выход удаляет её только в браузере, смена
  пароля старые сессии не закрывает. Чтобы выкинуть всех — смените `AUTH_SECRET`.
- **Проверка входа — в middleware**, обработчики API её не дублируют.
- **Нет лимитов** на размер загружаемого файла и число вызовов Claude.
- **Распознанные значения стоит просматривать глазами.** Модель может ошибиться, а текст внутри
  документа теоретически способен повлиять на её ответ.

## Переезд на droplet (позже)

Приложение писалось переносимым. Порядок:

1. **База → Postgres.** В `prisma/schema.prisma` поменять `provider = "sqlite"` на `"postgresql"`,
   в `.env` задать `DATABASE_URL=postgresql://…`. Выполнить `npx prisma migrate deploy`.
   (Схема без SQLite-специфичных типов, миграция чистая.)
2. **Файлы.** Скопировать `data/uploads/` на сервер (или смонтировать том); задать `DATA_DIR`.
3. **Секьюрность.** Сменить `APP_PASSWORD`, сгенерировать новый `AUTH_SECRET`, поставить за
   Cloudflare Tunnel + HTTPS. Cookie сессии автоматически станет `secure` в production.
4. **Whoop redirect.** Обновить `WHOOP_REDIRECT_URI` на публичный домен и тот же URL в кабинете Whoop.
5. Запуск: `npm run build && npm start` (или Docker).
